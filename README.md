# Annapurna Kitchen — static demo sample

Fictional pure-veg café & catering single-page site for **Project Weblu** outreach.

**Not a real restaurant.** Branding, menu, and contact details are placeholders. Imagery is decorative Unsplash stock.

## Contents

| File | Purpose |
|------|---------|
| `index.html` | Single-page demo |
| `styles.css` | Base, header, hero |
| `styles-more.css` | About, menu, catering, visit, footer, mobile nav |
| `script.js` | Mobile nav toggle only |
| `favicon.svg` | Sample mark |
| `_headers` | `X-Robots-Tag: noindex, nofollow` (Cloudflare Pages) |

## Demo safeguards

- Visible **Demo preview** badge (banner + footer)
- `<meta name="robots" content="noindex, nofollow">`
- `_headers` with `X-Robots-Tag: noindex, nofollow`
- CTAs point to `#reserve` with copy to replace numbers
- Address: `Your locality · Mumbai` (no fake real street)
- Footer disclaimer that this is outreach sample content

## Local preview

Open `index.html` in a browser, or serve the folder with any static server.

## Design notes

Warm cream / saffron–terracotta / deep green — distinct from teal seafood branding. Google Fonts: Fraunces + DM Sans. Vanilla HTML/CSS/JS only.
